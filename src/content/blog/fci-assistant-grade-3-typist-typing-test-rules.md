The **Food Corporation of India (FCI)** recruits **Assistant Grade-III (Hindi Typist) / सहायक ग्रेड-III (हिंदी टाइपिस्ट)** across its five administrative zones (North, South, East, West, and North-East).

The Phase-III typing skill test evaluates candidate proficiency on official administrative Hindi texts. Below are the official rules and guidelines.

---

## ⚡ Quick Exam Snapshot (TL;DR Fact Matrix)

| Parameter | Official FCI Hindi Typist Standard |
| :--- | :--- |
| **Recruitment Post** | Assistant Grade-III (Hindi Typist) |
| **Mandatory Medium** | **Hindi Typing on Computer** |
| **Required Speed Benchmark** | **30 Words Per Minute (WPM)** |
| **Key Depressions Equivalent** | **1,500 Keystrokes in 10 Minutes** |
| **Test Duration** | **10 Minutes** |
| **Mandatory Font** | **Mangal Unicode (Inscript / Remington GAIL)** |
| **Test Nature** | **Qualifying Only (Mandatory)** |
| **Backspace Permitted** | **Yes (Full Editing Enabled)** |
