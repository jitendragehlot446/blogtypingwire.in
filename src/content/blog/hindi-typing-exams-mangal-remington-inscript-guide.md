When preparing for government Hindi typing tests, choosing the correct font and keyboard layout is crucial. Many candidates practice for months on the wrong layout only to find their exam requires a different system.

---

## 1. Exam Compatibility Matrix

| Exam / Agency | Required Font | Permitted Layouts |
| :--- | :--- | :--- |
| **SSC (CGL, CHSL, Steno)** | **Mangal (Unicode)** | Inscript / Remington (Gail) / CBI |
| **Rajasthan High Court & RSSB** | **KrutiDev 010 / DevLys 010** | Remington Layout |
| **UP Police ASI / Computer Operator** | **Mangal (Unicode)** | Inscript / Remington Gail |
| **Allahabad & Patna High Court** | **Mangal (Unicode)** | Inscript / Remington Gail |
| **DSSSB (Delhi)** | **Mangal (Unicode)** | Inscript / Remington Gail |

## 2. Key Differences Breakdown

### 🅰️ Mangal Inscript (Government Standard)
* **Design**: Vowels on the left side of the keyboard, consonants on the right side.
* **Typing Halant**: Conjunct characters (like `क्य`, `प्र`, `त्र`) are made using the Halant key (`D` on Inscript).
* **System Integration**: Built into Windows 10 & 11 without third-party software.

### 🅱️ Mangal Remington Gail (Typewriter Layout on Unicode)
* **Design**: Traditional Remington typewriter key mapping mapped directly to Unicode glyphs.
* **Advantage**: Typists trained on legacy typewriter machines can type Unicode Mangal without relearning key positions.

### 🅲 KrutiDev 010 / DevLys 010 (Legacy Non-Unicode)
* **Design**: English ASCII key replacement.
* **Special Alt Codes**: Certain composite letters require memorizing Alt codes (e.g. `Alt + 0161` for `ऋ`, `Alt + 0216` for `क्र`).
