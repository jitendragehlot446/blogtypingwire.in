The **Official Notification of the High Court of Judicature at Allahabad** for recruitment to **Review Officer (RO) and Assistant Review Officer (ARO)** contains specific regulatory guidelines regarding the **Part-II Computer Knowledge Test (Typing Test)**.

This detailed guide analyzes the official notification clauses, NTA software mechanics, and exact marking criteria.

---

## ⚡ Official Notification Specifications (TL;DR Fact Matrix)

| Notification Parameter | Official Clause Specification |
| :--- | :--- |
| **Recruitment Authority** | High Court of Judicature at Allahabad |
| **Exam Conducting Agency** | National Testing Agency (NTA) |
| **Component** | Part-II: Computer Knowledge / Typing Test |
| **Medium** | English Typing on Computer Only |
| **Passage Length** | Exactly **500 Words** |
| **Time Allowed** | **20 Minutes** |
| **Minimum Required Speed** | **25.0 Words Per Minute (WPM)** |
| **Maximum Marks** | **50 Marks (Directly Added to Written CBT Merit)** |
| **Qualifying Cutoff Marks** | **25.0 Marks Out of 50 (Minimum 50%)** |
| **Negative Deduction Rate** | **0.1 Marks per Full Error / 0.05 per Half Error** |

## 1. Official Clause Breakdown: Part-II Marking Algorithm

According to the official scheme released by the High Court Registrar General and NTA:

`Final Marks = ( (Correct Words Typed / 500) × 50 ) - (Full Errors × 0.10) - (Half Errors × 0.05)`

### Error Deductions:
1. **Full Error (0.10 Mark Penalty)**:
   - Omission of an entire word from the 500-word legal text.
   - Substitution of a master word with an incorrect word.
   - Addition of unprinted words or extraneous symbols.
2. **Half Error (0.05 Mark Penalty)**:
   - Misspelled word (character level errors).
   - Inversion or transposition of letters.
   - Punctuation errors or improper spacing.

## 2. Examination Session Structure on Exam Day

1. **Shift Schedule**: Candidates sit for the 180-minute Part-I Objective CBT (200 questions / 200 marks).
2. **Break Period**: A strictly controlled 15-minute gap is provided where candidates remain seated at their terminals.
3. **Mock Typing Run (3 Minutes)**: Candidates test keyboard responsiveness and key action before the official 20-minute test unlocks.
4. **Official 20-Minute Test**: The timer begins automatically, presenting the 500-word passage.
