The **AIIMS Common Recruitment Examination (CRE)** for **Junior Administrative Assistant (JAA) / Lower Division Clerk** tests candidates on a 15-minute computer typing exam.

---

## 1. Speed & Duration Standards

| Parameter | English Typing | Hindi Typing |
| :--- | :--- | :--- |
| **Duration** | **15 Minutes** | **15 Minutes** |
| **Target Key Depressions** | **2,625 Keystrokes** | **2,250 Keystrokes** |
| **Net Speed Required** | **35 WPM** | **30 WPM** |
| **Error Penalty System** | Stroke Deduction (50 Strokes / Error) | Stroke Deduction (50 Strokes / Error) |

---

## 2. The AIIMS 50-Stroke Deduction Formula

$$\text{Net Keystrokes} = \text{Total Keystrokes Typed} - (\text{Mistakes} \times 50)$$

$$\text{Net Speed (WPM)} = \frac{\text{Net Keystrokes} / 5}{15 \text{ Minutes}}$$
