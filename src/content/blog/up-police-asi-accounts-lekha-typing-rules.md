The **Uttar Pradesh Police Recruitment and Promotion Board (UPPRPB)** recruits **Assistant Sub-Inspector of Police (Accounts / सहायक उप-निरीक्षक लेखा)** for financial and treasury operations across police headquarters, commissionerates, and district lines.

Unlike general clerk/ministerial posts that require 25 WPM Hindi and 30 WPM English, the **ASI Accounts** cadre has a specific **15 WPM Hindi** requirement. Below are the official rules and guidelines.

---

## ⚡ Quick Exam Snapshot (TL;DR Fact Matrix)

| Parameter | UP Police ASI (Accounts / Lekha) Standard |
| :--- | :--- |
| **Recruitment Cadre** | Assistant Sub-Inspector (Accounts) |
| **Mandatory Medium** | **Hindi Typing Only (Unicode Mangal Font)** |
| **Mandatory Keyboard Layout** | **Inscript Keyboard Layout Only** |
| **Required Speed Benchmark** | **15 Words Per Minute (WPM)** |
| **Minimum Accuracy Cutoff** | **85% Net Accuracy** |
| **Test Duration** | **15 Minutes** |
| **Passage Volume** | **Approx. 225 to 250 Words** |
| **Nature of Test** | **Qualifying Only (Mandatory)** |
| **Backspace Permitted** | **Yes (Full Editing Enabled)** |

---

## 1. Important Note on Inscript Keyboard Layout

* **Inscript Mandate**: UPPRPB strictly provides the **Mangal Inscript** layout. Remington GAIL is **NOT** available in UP Police typing examinations.
* **Practice Requirement**: Candidates accustomed to KrutiDev or Remington must train on the Windows Inscript keyboard layout to clear this exam.
