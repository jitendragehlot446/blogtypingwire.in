The **Rajasthan Staff Selection Board (RSSB / RSMSSB, Jaipur)** conducts the state examination for **Clerk Grade-II / Junior Assistant (LDC)** across government secretariats, subordinate offices, and RPSC.

The **Phase-II Typewriting & Efficiency Test carries 100 marks** that are directly merged with the written score.

| Test Component | Paper Name | Medium / Software | Duration | Maximum Marks | Min. Qualifying (36%) |
| :--- | :--- | :--- | :--- | :--- | :--- |

## 1. Speed Test Marking Mathematical Model

`Marks Awarded = (Net Key Depressions Typed / Benchmark Depressions) × 25`

* Target speed to secure the maximum **25 out of 25 marks** is **50 WPM (8,000 KDPH)**.
* Minimum speed to secure **9 qualifying marks** is **28 WPM (approx 4,480 KDPH)**.

---

## 2. Paper-2: Efficiency Test Tasks Breakdown

1. **Paragraph Operations**: Setting indents (First line 0.5", Hanging), applying justified text alignment, modifying paragraph line spacing (1.15 / 1.5).
2. **Typography**: Changing font face to Arial/Times New Roman, bolding key phrases, underlining legal statutes, strikethrough.
3. **Table Styling**: Inserting 4x4 tables, applying cell borders, merging cells, setting cell padding.
4. **Header & Footer**: Adding date, document title, and automated page numbers.
